# 数智命题师 · exam-maker —— 通用命题（出卷）智能体

依据**往年真题**为**任意课程**自动命制新卷的 Claude Code 技能。一句话流程：

> 给真题 → 解析成 LaTeX → 归纳考点建**双向细目表** → 提取试卷模板 → 按难度配比生成 **N 套**带**详细参考答案与分步评分标准**的新卷 → 编译/转成 `latex/docx/md` → **教师选卷**。

每个重活步骤都启动子代理"分析 + 核对"，计算题**逐题 sympy 验算**、概念题给"参考答案 + 采分点 + 出处"，关键环节**教师人工确认**（教育主责）。

## 能做/不能做

**能做**
- 任意课程：理工科（数/理/工/CS，有可计算答案）与文科/概念科（史/法/管理/医学概念…）都支持，自动判定核验方式。
- 真题输入：`pdf` / `docx` / `doc` / `tex` / `md`，一份或多份。
- 结构对齐真题：题型、题量、单题分值、总分、时长与真题一致。
- 难度可核算：默认按**分值** `基础60% / 中等30% / 难10%`（可改）；生成后逐套核算达标。
- 不抄原题：计算题同型变形（换数据、答案整齐），概念题换情境/换设问；套与套之间、对真题均不重复。
- 交付：含详细答案 + 分步评分标准；`latex`（可编译）+ 可转 `docx / md`。

**不做 / 需人把关**
- 不替代教师命题：**教师是最终审核人**，证明题措辞、难度判断、开放题评分要点请教师终审。
- 不虚构事实：概念题涉及硬事实时联网核实并给出处，但仍需教师核对。
- 不保证"押中考题"：目标是覆盖考点、结构对齐、可用于模拟/练习。

## 安装

技能需放进 Claude Code 的技能目录 `~/.claude/skills/`（与已装的 `teaching-reform-proposal` 同法）。

**方式 A：软链接（推荐，改动即生效）**

```bash
# Git Bash
ln -s "/c/Users/lyang/OneDrive/智能体大赛/exam-maker" ~/.claude/skills/exam-maker
```

```powershell
# PowerShell（需管理员或开启开发者模式）
New-Item -ItemType SymbolicLink -Path "$env:USERPROFILE\.claude\skills\exam-maker" `
  -Target "C:\Users\lyang\OneDrive\智能体大赛\exam-maker"
```

**方式 B：直接复制** 整个 `exam-maker/` 文件夹到 `~/.claude/skills/exam-maker/`。

安装后，在 Claude Code 里输入 `/` 应能看到 `exam-maker`，或直接用自然语言描述任务自动触发（见下）。

## 环境依赖

技能开工时会**自动探测**并对缺失项给降级方案，但备齐后体验最好：

| 工具 | 用途 | 检测 | 缺失时 |
|---|---|---|---|
| **pandoc** | tex↔docx↔md 转换（核心） | `pandoc --version` | 装 pandoc；否则只能出 latex |
| **python + sympy/numpy** | 计算题逐题验算 | `python -c "import sympy"` | `pip install sympy`；退 numpy 数值验 |
| **LaTeX 引擎**（`xelatex`/`latexmk`/`tectonic`） | 本地编译出 PDF | `xelatex --version` | 跳过本地编译，交 Overleaf 源 |
| **LibreOffice `soffice`** | 读 `.doc` 旧格式 | `where soffice` | 请把 `.doc` 另存为 `.docx` |

> **没有 LaTeX 引擎也能用**：成品 `.tex` 可在 [Overleaf](https://overleaf.com)（编译器选 XeLaTeX）直接编译，或让技能转成 `docx` 交付。
> **想本地编译**：装单文件免配置的 [tectonic](https://tectonic-typesetting.github.io/)（Windows 可 `curl` 官方 release 的 `x86_64-pc-windows-msvc.zip`）。

## 快速开始（3 步）

1. **把往年真题放进一个目录**（如 `D:\exam\`，放 2–3 份最有代表性的真题，格式不限）。
2. **在该目录打开 Claude Code**，输入一句任务描述（见下方提示词）。
3. **配合三个确认点**：细目表 → 模板 → 选卷。技能会停下来问，你确认或调整即可。

成品默认写回真题所在目录，中间产物在其下 `exam-build/`。

## ⭐ 通用提示词模板（可直接复制）

技能靠自然语言触发——**把下面模板里的〈占位〉换成你的信息即可**。要素齐了效果最好：**课程名 · 真题位置 · 范围 · 难度 · 套数 · 输出格式**。

### 1. 最简（真题就在当前目录）
```
根据这个目录里的往年真题，用 exam-maker 出 8 套《〈课程名〉》期末模拟卷，
带详细参考答案和分步评分标准。
```

### 2. 指定范围 + 难度 + 格式 + 套数
```
用 exam-maker 出 〈6〉套《〈概率论与数理统计〉》期末卷：
- 真题在 〈./真题/〉 目录；
- 范围：〈到假设检验为止，不含方差分析〉；
- 难度按分值 〈基础60% / 中等30% / 难10%〉；
- 输出 〈docx〉，每套含参考答案与评分标准。
```

### 3. 我已有考纲/知识点清单
```
按我给的考纲（见 〈syllabus.md〉 的知识点清单）和 〈./past/〉 里的真题，
出 〈4〉套《〈数据结构〉》半期卷，题型与分值对齐真题，输出 latex。
先把考点分类做成双向细目表给我确认，再出卷。
```

### 4. 概念/文科课程
```
根据本目录《〈中国近现代史纲要〉》历年真题，出 〈5〉套期末卷：
- 题型含名词解释/简答/材料分析/论述，与真题一致；
- 每题给参考答案 + 采分点 + 依据出处，涉及史实请联网核实；
- 输出 docx。
```

### 5. 只做某一步（人工干预）
```
先别出卷。用 exam-maker 只做前两步：
把 〈./exam/〉 里的真题解析成 LaTeX，并归纳考点做成双向细目表。
我确认考点归类后你再继续。
```

### 6. 调整后继续
```
细目表我改好了（把"〈极限〉"和"〈连续〉"并成一类，"〈中值定理〉"标为必考）。
按这个继续出 〈8〉套，其余不变。
```

### 7. 追加/换难度重出某套
```
第 〈3〉套整体偏难，重出这一套，难度降到 〈基础70%/中等25%/难5%〉，
其他七套不动。
```

### 8. 全参数版（power user，一次说清）
```
用 exam-maker 命题：
COURSE=《〈线性代数（经管类）〉》
PAST_PAPERS=〈./real/〉（pdf 多份）
SCOPE=〈全书，重点在特征值与二次型〉
DIFFICULTY=〈基础60/中等30/难10，按分值〉
N_SETS=〈8〉
OUTPUT_FILE_TYPE=〈latex〉
要求：结构对齐真题、每题 sympy 验算、含分步评分标准、套间不重复；
细目表和模板做好先给我确认，最后我选卷。
```

> 触发不了时：直接输入 `/exam-maker`，或在句首加"**用 exam-maker 技能**"。

## 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `COURSE` | 从真题推断 | 课程名，可不给 |
| `SCOPE` | 由真题归纳 | 命题范围/章节/考点分类，可给可不给 |
| `PAST_PAPERS` | 与输出同目录 | 真题：`pdf/docx/doc/tex/md`，一份或多份 |
| `OUTPUT_FILE_TYPE` | `latex` | 成卷格式：`latex`/`docx`/`md` |
| `DIFFICULTY` | 基础60/中等30/难10 | **按分值**的难度配比，可改（半期卷/竞赛卷等） |
| `N_SETS` | `8` | 生成套数 |
| `WORKDIR` | 真题所在目录 | 成品写回此处；中间产物在 `exam-build/` |
| `VERIFY_MODE` | `auto` | `auto`/`computational`/`conceptual`/`mixed` |

**难度定义**（跨学科）：基础＝单一考点、直接套用、步骤少；中等＝2 考点综合或需一步转化；难＝核心方法综合/严谨论证，但**不偏不怪不超纲**。默认 60/30/10 适合公共课/经管；**数学/物理专业课**建议按真题实测调（技能会先报真题实际分布供你定）。

## 工作流程与人工确认点

```
步骤0 探测环境、对齐参数
步骤1 真题 → LaTeX（子代理转写 + 校对）           产物 source-*.tex
步骤2 归纳考点 → 双向细目表      ⏸【确认1：考点归类】 产物 blueprint.md/.jsonl
步骤3 提取试卷模板              ⏸【确认2：题型/分值】 产物 template.md
步骤4 难度配比落到模板（分值核算）
步骤5 生成 N 套（命题子代理 + 逐题核验）           产物 paper-1..N.tex + 验算脚本
步骤6 编译/转换 + 交付          ⏸【确认3：选卷】     产物 .pdf/.docx/.md + ledger.md
```

三个 ⏸ 是**教师主责**的干预点：可调整考点归类、改题型/总分、最终挑选采用哪几套。不想被打断可在提示词里说"全流程跑完再给我看"。

## 产物说明

在 `WORKDIR/exam-build/`：

| 文件 | 内容 |
|---|---|
| `source-*.tex` | 真题忠实转写的 LaTeX（步骤1） |
| `blueprint.md` / `blueprint.jsonl` | 双向细目表（考点×难度×分值）+ 逐题映射 |
| `template.md` | 试卷模板 + 难度核算表 |
| `paper-1..N.tex` | 各套试卷（试题 + 参考答案 + 分步评分） |
| `paper-1..N.pdf/.docx/.md` | 编译/转换后的成品 |
| `verify_papers*.py` | 计算题验算脚本（可复跑） |
| `ledger.md` | 防重台账 + 完成确认（覆盖了哪些考点、用了什么数据） |
| `to_convertible.py` | latex→docx/md 前的"转换安全替换"工具 |

选定的成品会（经你同意后）复制到 `WORKDIR/`。

## 完整实例：高等代数 8 套

本仓库 `../exam1/` 就是一个真实跑通的例子：输入三份《高等代数-1》真题（`2021/2023/2024级-A.pdf`），输出在 `../exam1/exam-build/`：

- 8 套平行卷 × 4 格式（`.tex/.pdf/.docx/.md`），每套 100 分、6 大题（含 1 道开放题）；
- **102/102 sympy 验算 PASS**、8 套 **tectonic 编译零错误零 Overfull**、docx **零 warning**、md **步骤分零丢失**；
- 难度 46/32/22（对齐真题）、K1–K21 考点全覆盖、证明命题两两互异。

可打开 `../exam1/exam-build/paper-1.pdf` 与 `blueprint.md` 直观感受产物形态。

## 常见问题与排错

**Q：技能没自动触发？**
A：输入 `/exam-maker`，或句首写"用 exam-maker 技能"。确认已装到 `~/.claude/skills/exam-maker`。

**Q：PDF 是扫描件/手写，能认吗？**
A：能。步骤1 用视觉逐页识读；把握不准处会标 `% TODO 存疑` 交你核对，不臆造。

**Q：没装 LaTeX，出不了 PDF？**
A：默认交可编译的 `.tex`（Overleaf 选 XeLaTeX）+ `docx`。要本地 PDF 就装 tectonic/MiKTeX。

**Q：docx 里公式/分值丢了？**
A：用了 `scripts/to_convertible.py` 做转换安全替换后再 pandoc，并会"转完必查"。**在 Windows/Git Bash 上务必用 Python 做替换，不要用 sed**（反斜杠转义会静默失效）。

**Q：文科课程也能验算吗？**
A：文科走"复核轨"——参考答案 + 采分点 + 出处 + 子代理复核（必要时联网核实事实），而非 sympy。

**Q：难度总不达标？**
A：难度按**分值**核算，可把大题拆成不同难度小问来凑比例；也可直接把 `DIFFICULTY` 改成你要的数字。
