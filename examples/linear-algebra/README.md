# 范例：线性代数（III）经管类 —— 一个可计算学科的完整"手法库"

这是本通用命题技能在**一门具体课程**上的落地范例，供命制**可计算学科**时照样式建自己的"题型变形手法库"。它对应 SKILL.md 步骤 5、`references/blueprint-and-difficulty.md` 第三节"可计算学科变形"。

- `slot-design.md`：四川大学经管类《线性代数（III）》期末/半期卷的**逐题位变形手册**——每个题位（填空/计算/解答/证明）列出可轮换的"变形手法"、反向构造整数化数据的技巧，以及一张"出卷登记表"（=通用流程里的 `ledger.md` 防重台账的具体形态）。

怎么用它：
- 命同一门课时，可直接把 `slot-design.md` 当手法库和防重台账续写。
- 命**其它可计算课程**（高数、概率统计、物理、离散、算法…）时，**照它的结构**为你的题型建一份新的手法库：每个题位 → 可轮换设问范式 + 反向构造数字/结果整齐的技巧 + 已用数据登记。
- 命**概念学科**时不用它，改走 `references/quality-gates.md` 的复核轨（情境/设问变形 + 参考答案+采分点+出处）。

> 这份范例也展示了本技能的固定 100 分结构、60/30/10 难度核算、逐题 SymPy 验算、分步评分标准是如何在真实课程上成形的。
