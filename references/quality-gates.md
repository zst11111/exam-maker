# 学科自适应核验 · 子代理提示词 · 红线

支撑 SKILL.md 步骤 1–6 的"分析 + 核对"。两条核验轨道按学科自动选择，后半是可直接复制改写的**子代理提示词模板**。

---

## 一、判定学科轨道（`VERIFY_MODE`）

`auto` 时看真题：题目答案**能否用程序判定对错**。
- **computational（可计算）**：数学、物理、部分化学/工科/CS 算法——答案是数、式、矩阵、真值、可运行代码。→ **脚本验算轨**。
- **conceptual（概念）**：文/史/哲/法/医学概念/管理/语言——答案是论述、名解、案例分析、判断说理。→ **复核轨**。
- **mixed（混合）**：一张卷里两类都有（如"计算 + 论述"）→ **逐题按其类型走对应轨**。

---

## 二、脚本验算轨（可计算学科 · 红线，不可跳过）

复制 `scripts/verify_template.py` 为本次脚本（放 `%TEMP%` 或 `exam-build/`），**给每一道题至少写一条 `chk()` 断言**，跑到 `TOTAL: n/n`：
- 断言覆盖真正的答案对象：行列式值/特征值集合/通解代回/秩与 RREF/逆矩阵/相容条件/极值/物理量数值等。
- **FAIL 一律改题面数据重构、重验，禁止改口答案迁就**（"先定答案、反向构造"就是为了这条）。
- 答案要"整齐"的题（如需整数根的行列式），先让脚本**打印多组候选**再挑整齐的那组。
- **无 sympy 时降级 numpy**：数值近似 + 容差（如 `abs(x-round(x))<1e-9` 判整数、`np.allclose` 判矩阵相等），符号因式分解类改为"取几个数值点验证恒等"。
- 交付要报"验算通过数"（如 `92/92`），并把脚本留档。

## 三、复核轨（概念学科）

命题时每题就要产出三件套：**参考答案 + 评分要点（采分点及分值）+ 依据/出处**；主观题给**分层评分标准**。然后派**复核子代理**逐题按清单核对：

- [ ] **答对设问**：参考答案确实回答了题目问的东西，不跑题、不答非所问；
- [ ] **采分点完备且分值合计=题分**：要点可操作、分值可加总；主观题有"要点分 + 论证/表达分"的层次；
- [ ] **事实准确**：涉及定义、年代、条文、数据、机制的**硬事实**必须正确——拿不准的**联网核实**（`WebSearch`/`WebFetch` 查权威来源）并在依据里注明出处；
- [ ] **无歧义/无多解争议**：题干条件充分、指向唯一（除非有意开放，则评分标准要覆盖多种合理答案）；
- [ ] **对齐考点与难度**：真考到 `blueprint.jsonl` 标的考点，难度与标注一致；
- [ ] **不超纲不偏怪**：难题是大纲内综合迁移，不是冷僻知识。

> 联网核实是**核对事实**、不是抄袭；引用观点/材料要能溯源，避免把未经核实的说法写进参考答案。

## 四、通用答案红线（两轨都适用）

- 每题都有"标准答案 + 得分点"，`\score{}`（或采分点）之和＝题分；每套总分达标。
- **送分题真送分**：可计算题可口算/常规流程整数落地；概念送分题是直接再认/复述，不埋坑。
- **难题真有区分度但不超纲**：核心方法综合，不靠偏题怪题制造难度。
- **形态多样、不与真题/它套同形（多样性红线）**：同一考点在 N 套间须换"变形轴"（正逆 / 任务类型 / 表征 / 含参 / 综合 / 情境 / 粒度），**严禁只换数字照搬设问**；与真题可同考点、不可同形态。判重按"考点 + 变形轴 + 设问范式"，不看具体数字（见 blueprint-and-difficulty.md 三、四节）。
- 解答**规范完整、步骤可复现**；行变换/推导标注清楚，读者能照着走一遍。

## 五、子代理提示词模板（步骤 2–6 的"启动子代理分析核对"）

每个模板都是"**做 + 自查**"，主线只接收自查通过的产物。派"核对子代理"时，把"做"的产物和原始来源一起给它，让它**独立比对**而不是复述。

**① 转写子代理（步骤1·PDF→LaTeX）**
> 你是学科转写员。逐页把这份真题第 X–Y 页忠实转成 LaTeX：正文、公式（含上下标/矩阵/正负号）、表格、图注、每题**分值**都要，题号原样保留。排版乱/手写/模糊而把握不准处，标 `% TODO 存疑` 不要臆造。产出 `.tex` 片段。

**② 校对子代理（步骤1·核对）**
> 这是原始 PDF 第 X–Y 页与转写出的 LaTeX。逐题**独立比对**：公式、下标、正负号、矩阵元、分值、题号有无错读/漏读。列出差异并给出修正后的 LaTeX；确认无误才回"PASS"。

**③ 考点分析子代理（步骤2）**
> 依据这些真题 `.tex`（和用户给的 SCOPE，若有），逐题判定主考考点、题型、分值、难度、认知层次、设问范式，产出 `blueprint.jsonl`（每题一行）与人读的**双向细目表** `blueprint.md`（考点×难度分值矩阵 + 考点清单 + 频次）。归类粒度以"能指导命题"为准。格式见 references/blueprint-and-difficulty.md。

**④ 细目表核对子代理（步骤2·核对）**
> 检查 `blueprint.jsonl`/`blueprint.md`：分类是否一致（同型题归同点）、分值合计是否=各卷总分、难度分布是否合理、有无漏归/错归的题。列问题清单并给修订建议。

**⑤ 模板子代理（步骤3）**
> 从真题抽取试卷模板：题型序列、各型题量、单题与小问分值、总分、时长、抬头/须知/评分说明风格、排版体例。产出 `template.md`（结构表，Σ分值=总分）。多份真题结构不一致时，指出差异并建议采用哪一版为基准。

**⑥ 命题子代理（步骤5·每套或每批）**
> 依据 `blueprint.md` + `template.md` + 难度核算 + `ledger.md`，命制第 K 套新卷。**动手前先为每个题位列一张"考点 + 变形轴①-⑧ + 设问范式"清单，与 ledger 及真题比对，确保与真题/已生成各套"不同形态"——不能只换数字照搬设问；同考点优先选未用过的变形轴**（轴与变形算子见 blueprint-and-difficulty.md 三节）。再：先定答案结构反向构造题面；命中难度配比与总分；覆盖分配到本套的考点。给出【试题】+【详细参考答案与分步评分标准】。可计算题保证结果整齐并预备验算断言；概念题给"答案+采分点+出处"。完成后把本套各题位的"考点 + 变形轴 + 结构手法/情境 + 关键数据"写进 ledger。

**⑦ 核验子代理（步骤5·核对，按轨道 + 多样性）**
> **多样性核对（两轨都做）**：逐题把本套与真题、与已生成各套的**同考点**题目比对"设问范式/变形轴"——若相同（仅数字不同即算相同），标记"雷同"并要求换轴重命；统计每个高频考点在全批用过的轴，指出扎堆的轴。
> **正确性核对**：可计算——把本套每题写成 `chk()` 断言补进验算脚本并运行，回报 `n/n` 与任何 FAIL（连同应改数据）；概念——按第三节清单逐题核对，列出不合格项与修法。

**⑧ 转换核对子代理（步骤6）**
> 对照 `paper-K.tex` 与转出的 `paper-K.{docx,md}`：每题在否、公式有无丢失/变形、表格完整否、`\score`/采分点与总分在否、题号连续否。列出缺失并给修法（改转换安全副本重转 / 手工补齐）。
