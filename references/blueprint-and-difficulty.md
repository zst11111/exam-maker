# 细目表 · 难度配比 · 变形 · 防重

本手册支撑 SKILL.md 的步骤 2–5：如何从真题建**双向细目表**、如何把**难度配比**落到模板、如何**变形出新题不抄原题**、如何用**台账防重复**。适用任意课程；可计算学科（数学/物理/部分工科与 CS）与概念学科（文/史/法/医学概念/管理等）分别给了做法。

---

## 一、考点提取（步骤 2 · 考点分析子代理）

对每一道真题小题，判定并记录：**主考考点**（1 个为主，可带次要考点）、**题型**、**分值**、**难度**（基础/中等/难）、**认知层次**、**关键设问方式**。

- 若用户给了 `SCOPE`（考纲/知识点清单/题型分类），**对齐它的口径**归类；未给则**自下而上**归纳：先给每题拟一个考点标签，再把同义标签合并成一份"考点清单"，清单粒度以"能指导命题"为准（既不要粗到'第三章'，也不要细到'某一道题'）。
- **认知层次**用一套通用分级（源自 Bloom，便于跨学科）：`记忆 < 理解 < 应用 < 分析 < 评价/综合`。它与难度相关但不等同——一道"应用"题可以是送分，一道"分析/综合"题通常是中等或难。
- 覆盖度：统计每个考点在真题中出现的**频次与分值权重**，作为新卷"哪些必考、哪些轮换"的依据。

### 产物 A：`blueprint.jsonl`（每题一行，机器可读）

```json
{"src":"2024-A","no":"三.2","type":"解答题","points":12,"kp":["特征值与特征向量","相似对角化"],"difficulty":"中等","cognition":"应用","stem_kind":"给矩阵求可对角化条件","note":"含参"}
```

字段：`src` 来源卷、`no` 题号、`type` 题型、`points` 分值、`kp` 考点(可多)、`difficulty`、`cognition`、`stem_kind` 设问范式（用于变形轮换）、`note`。

### 产物 B：`blueprint.md`（人读的双向细目表）

**双向细目表**＝考点（行）× 认知层次/难度（列），单元格填分值/题数，是组卷的总蓝图：

| 考点 \ 难度 | 基础 | 中等 | 难 | 合计分 | 真题频次 | 备注(必考?) |
|---|---|---|---|---|---|---|
| 考点A | 6 | 0 | 0 | 6 | 3 | 必考 |
| 考点B | 3 | 6 | 0 | 9 | 2 | |
| … | | | | | | |
| **列合计** | **≈60%** | **≈30%** | **≈10%** | **100** | | |

同时给出：考点清单（带定义/边界）、题型分布、每考点的"常见设问范式"（供变形轮换）。**这张表交教师确认后才进入命题**——教师可改归类、调权重、标必考/删除。

## 二、难度：定义、判定、配比核算（步骤 4）

### 通用难度定义（跨学科）

| 难度 | 判据（满足多数即归此级） | 命题手感 |
|---|---|---|
| **基础/送分** | 单一考点；直接套用定义/公式/标准流程；步骤少（可计算学科≤2步且数字整齐；概念学科为再认/复述/直接判断） | 认真复习必得分 |
| **中等** | 2 个考点综合，或需一步非显然转化/选择方法；含参分类讨论的常规情形；概念学科需比较/解释/简单应用到新情境 | 会而不难 |
| **难** | 核心方法/多考点综合、严谨论证、建模或多步推理；概念学科为评价/论证/迁移到复杂情境 | 有区分度、但**不偏不怪不超纲** |

判定要落到 `blueprint.jsonl` 的 `difficulty` 字段；大题可按小问分别判定（如 `(1)中等 +(2)难`）。

### 配比按"分值占比"核算，不是按题数

目标（默认）：`Σ基础/总分 ≈ 60%`、`Σ中等 ≈ 30%`、`Σ难 ≈ 10%`，容差 ±3%（可被 `DIFFICULTY` 覆盖）。

**落位算法**：遍历模板的每个题位（含大题的小问），给它指派难度并累加分值；不足/超标时，**优先把某个大题拆成不同难度的小问**来微调（例如"解答题 12 分 = 送分 6 + 中等 6"或"= 中等 6 + 难 6"），这是命中比例最灵活的杠杆。核算示例（线代真题结构）：

```
送分60 = 填空18 + 计算30 + 解答1(12)
中等30 = 解答2(12) + 解答3(1)(6) + 证明1(8) + 证明2(1)(4)
难 10 = 解答3(2)(6) + 证明2(2)(4)
```

把这三行难度核算并入 `template.md`，并让每一套生成后都重算一遍（可写 6 行 Python 求和自检）。

### 覆盖与均衡（N 套之间）

- **单套**：独立命中难度配比与总分；不必覆盖全部考点。
- **N 套合计**：覆盖细目表的主要/必考考点；同一题位在多套间**轮换考点与设问范式**，避免"每套第 X 题都考同一个点、同一种问法"。

## 三、变形出新题：多样化，不抄原题（步骤 5 命题子代理）

原则：**先定答案结构，再反向构造题面**——先决定"答案长什么样、考哪个点、几步能到"，再倒推题面数据/情境，确保答案整齐、路径可控。

> **核心红线（多样性）：同一考点在 N 套之间必须"换形态"，不能只换数字。** 只改数据、照搬真题设问，是最差做法——它让 N 套卷高度雷同、可被学生押题、也谈不上"命制"。真正的变形是**换提问的角度**。参照真题本身：好试卷同一考点会在不同年份/不同题以不同形态出现（如"伴随矩阵"既考"求 A\*"，也考"由 A\*X=0 基础解系个数求 rank A"、"证 (AB)\*=B\*A\*"、"反对称 A\* 也反对称"）。

### 变形算子：对同一考点，换一个轴 = 一种新形态

| 轴 | 含义 | 例（以"伴随矩阵"或"秩"为例） |
|---|---|---|
| ① 正 ↔ 逆 | 正求 vs 反求/反构造 | 给 A 求 A\* ↔ 由 A\* 反推 A 或 A 的性质；求根 ↔ 由根构造多项式；求秩 ↔ 由秩定参数 |
| ② 任务类型 | 计算 / 判定说理 / 证明 / 举例 / 判断改错 / 设计 | 求 A\* ↔ 证 (AB)\*=B\*A\* ↔ 判断"A 可逆 ⟺ A\* 可逆"并说明 ↔ 举例 |
| ③ 表征 | 换语言：矩阵 / 向量组 / 方程组 / 线性映射 / 二次型 / 分块 / 多项式 | 秩：数值矩阵秩 ↔ 向量组秩 ↔ 二次型秩 ↔ 含参矩阵秩 ↔ 抽象 rank(AB) 不等式 |
| ④ 抽象度 | 具体数字实例 ↔ 抽象条件下一般证明 | 具体 A 直接算 ↔ "设 A 满足…，证明…" |
| ⑤ 含参化 | 定值 → 含参数、需分类讨论 | 定矩阵 ↔ 含参 a，讨论 A\* / 秩 / 解 随 a 的变化 |
| ⑥ 综合 | 与相邻考点耦合成一道题 | 伴随 + 行列式性质 + 秩 连环问；方程组解 + 线性无关 综合 |
| ⑦ 情境/载体 | 套应用/实际/史料/案例背景（尤文科与应用题） | 用秩判断电路/网络/迁移模型可解性；用方程组解经济配比问题 |
| ⑧ 提问粒度 | 填空 / 选择 / "下列说法是否正确并改正" / 一题多问递进 | "关于 A\* 的四个命题判断真伪并改正错误者" |

### 变形规则（红线）
- **同考点跨套换轴**：某考点在 8 套里出现多次，应覆盖尽量多的轴，**严禁 N 次都是"求…"只换数字**。轴用尽再复用时，数据/情境须全新。
- **不与真题同型**：可与真题**同考点**，但不应**同形态**。真题若"给矩阵求伴随"，新卷该考点优先换方向/表征/任务（如"由 A\* 的秩推 A 的秩"），而非照抄"给另一个矩阵求伴随"。
- **基础题也要轮换**：送分题可用较熟悉的范式，但 N 套间仍须在 ①②③ 轴上轮换，避免整批雷同；中难题必须**多轴组合**（如 逆 + 含参 + 综合）。
- **动手前先列"变形轴清单"**：为本套每个题位选定"考点 + 变形轴 + 设问范式"，与台账比对确认不与真题/它套同形态，再命题。

### 可计算学科（数/理/工/CS）
- 结构手法库（每题位可轮换的题型结构与整数化技巧）见 `examples/linear-algebra/slot-design.md`——它给**结构多样性**；再叠加上面 8 轴给**形态多样性**，两者都要用。仅有结构手法而设问千篇一律，仍算多样性不足。
- 每题过脚本验算（见 `quality-gates.md`），FAIL 改题面重构，禁止改口答案。

### 概念/文科学科
- 主用 ②⑦⑧ 轴：换任务（复述→比较→评析→迁移到新情境）、换情境/材料（案例、史料、条文、临床/管理背景）、换粒度（名解/简答/材料题/论述/判断改错）。
- 保持真题题型与分值；每题给"参考答案 + 采分点 + 出处"，主观题给分层评分标准；事实必要时联网核实（见 `quality-gates.md`）。

## 四、防重台账 `exam-build/ledger.md`（步骤 5 每套追加）

防止与真题、与已生成各套重复。按**题位**登记每套用了什么，命题前先查、命题后即追加。

| 题位 | 卷1 | 卷2 | … | 卷N |
|---|---|---|---|---|
| 题位1 | 考点 + **变形轴①-⑧** + 结构手法/情境 + 关键数据 | … | | |
| 题位2 | … | | | |

- 登记必含**变形轴**：可计算学科＝考点 + 轴 + 结构手法 + 关键数字/矩阵/参数；概念学科＝考点 + 轴 + 情境/材料 + 设问角度。
- **判重看形态不看数字**：同考点若"轴 + 设问范式"与真题或已生成某套相同，即使数字全换，也**算重复，须换轴重命**。仅换数字不算新题。
- **每考点跨套轴覆盖自检**：为每个高频考点统计已用过的轴，命新套时优先选**未用过的轴**；真题已密集使用的形态在新卷里降频。
- "考性质、答案为特殊值(如 0)"这类**押题点每批限量**（如至多一套一次），避免套路预期。
- 台账是判重唯一裁判；轴与结构都用尽时才允许复用，且数据/情境必须全新。
